Leonida Route Map is a road-atlas-inspired offline guide to all 55 GTA VI PS5 trophies. It pairs a locally saved checklist, grade and point meters, searchable filters, spoiler protection and JSON backups with a four-exit platinum roadmap and source-linked guidance. The Chapter 1 meditation is flagged as potentially missable; unresolved launch-day triggers are labelled rather than invented.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

## Sources

Official names, descriptions and grades are preserved from the bounty starter and cross-checked with [PSNProfiles](https://psnprofiles.com/trophies/43531-grand-theft-auto-vi) and [Exophase](https://www.exophase.com/game/grand-theft-auto-vi-psn/trophies/). Original paraphrased guidance draws on [PowerPyx](https://www.powerpyx.com/gta-6-grand-theft-auto-vi-trophy-guide-roadmap/) and [Push Square](https://www.pushsquare.com/guides/gta-6-trophy-guide-and-roadmap), researched on 19 November 2026. TrueTrophies supplies the hidden-trophy cross-check. Each trophy exposes its own sources; links load only when clicked.
