Leonida Route Map is a road atlas for the 55 GTA VI trophies on PS5. Start with the Chapter 1 checkpoint, then follow the exits for collections, activities, and cleanup. Open app/index.html in Chrome or run `node serve.ts` and visit http://localhost:8080. Your checklist stays in your browser; use Save & settings to move it as JSON.

## Sources

The kit preserves the PlayStation wording as listed by [PSNProfiles](https://psnprofiles.com/trophies/43531-grand-theft-auto-vi) and [Exophase](https://www.exophase.com/game/grand-theft-auto-vi-psn/trophies/). The field guide cites [PowerPyx](https://www.powerpyx.com/gta-6-grand-theft-auto-vi-trophy-guide-roadmap/), [Push Square](https://www.pushsquare.com/guides/gta-6-trophy-guide-and-roadmap), and other guides at the relevant trophy. The Chapter 1 meditation is an insurance stop, not a confirmed requirement.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
